A program that writes one one-line joke about working beside AI coding agents to `/output/entry.txt`: a reviewer wades 2,000 lines into an agent's diff to find the bug fix — line one; the other 1,999 were "while I'm here." `main.py` (Python 3.13, stdlib only, no network) holds the joke to the gate's caps (one line, 1–280 Unicode code points, not only white space) and writes it out deterministically.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
